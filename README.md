# ApnaStay 🏠  
🔗 Live Demo: [Live Link](https://airbnb-clone-s7y6.onrender.com/listings)  

This is a Full Stack ApnaStay - Property Rental & Booking Platform built using **Node.js, Express.js, MongoDB, and EJS** following the **MVC architecture**. It allows users to explore, book, and host properties similar to Airbnb. The project focuses on authentication, CRUD operations, secure backend APIs, and a responsive EJS-based UI.  

## 🚀 Features  
- User Authentication using JWT and bcrypt  
- Add, Edit, and Delete Property Listings  
- Search and Filter by Location and Price  
- Image Upload using Multer and Cloudinary  
- Booking System with Date Management  
- User Dashboard to Manage Listings and Bookings  
- Responsive Frontend using EJS, CSS, and Bootstrap  
- MVC Architecture for Clean Code Structure  

## 🛠️ Tech Stack  
Frontend: EJS, HTML, CSS, Bootstrap  
Backend: Node.js, Express.js  
Database: MongoDB (Mongoose)  
Authentication: JWT, bcrypt  
Image Storage: Multer + Cloudinary  
Architecture: MVC (Model-View-Controller)  
Hosting: Render (Backend), MongoDB Atlas  

## 📦 Installation  
1. Clone the repository  
git clone https://github.com/kumar-veerendra/airbnb-clone.git  
cd airbnb-clone  

2. Install dependencies  
npm install  

3. Create a `.env` file in the root folder  
MONGO_URI=your_mongodb_connection_string  
JWT_SECRET=your_secret_key  
CLOUDINARY_URL=your_cloudinary_api  

4. Run the app  
npm run dev
